## Quarter 2 Project Brainstorming
**1. What is the most interesting topic covered in your domain this quarter?**
The most interesting topic that I found particularly interesting within my domain this quarter was learning about how memory is managed within AI. Rather than store and memorize every interaction, the agents need to determine which tasks are actually worth remembering, since agents need to determine what information is still relevant. I find this interesting because it resembles how humans selectively retain information, and improving this process could make AI agents more efficient and reliable.
